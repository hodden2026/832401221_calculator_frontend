# Front-End and Back-End Separation Calculator — Frontend

## 1. Project Introduction

This repository contains the frontend of the Front-End and Back-End Separation Calculator System.

The frontend is responsible for:

- User interface presentation
- Calculator button interaction
- Expression input
- Sending calculation requests to the backend
- Displaying calculation results
- Displaying calculation history
- Searching calculation history
- Sending history deletion requests
- Displaying backend error messages

The core mathematical calculation is NOT performed by the frontend.

The final calculation result is generated by the backend API.

## 8. Front-End / Back-End Connection

The backend API base URL is configured in `script.js`:


## 9. Main APIs

### Calculate

```http
POST /api/calculate
```

Example request:

```json
{
    "expression": "(1+2)*3"
}
```

Example response:

```json
{
    "success": true,
    "expression": "(1+2)*3",
    "result": 9,
    "history_id": 1
}
```

### Query History

```http
GET /api/history
```

### Delete Specified History

```http
DELETE /api/history/{id}
```

### Clear All History

```http
DELETE /api/history
```

### Backend Health Check

```http
GET /api/health
```

## 13. Important Architecture Rule

The frontend never directly calculates the final mathematical result.

The process is:

```text
User Input
    ↓
Frontend
    ↓
POST /api/calculate
    ↓
Backend
    ↓
Expression Parsing
    ↓
Calculation
    ↓
Database
    ↓
JSON Response
    ↓
Frontend Display
```

If the backend service is stopped, the frontend cannot independently obtain a new valid calculation result.
